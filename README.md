# Data Structures and Algorithms in Java

A comprehensive collection of Data Structures and Algorithms implementations in Java for learning, reference, and interview preparation.

## Overview

This repository contains well-documented implementations of fundamental data structures and algorithms commonly used in computer science and software development. All code is written in Java and includes examples and test cases.

## Contents

### Data Structures
- Arrays and Lists
- Stacks and Queues
- Linked Lists
- Trees (Binary Trees, BST, AVL, etc.)
- Graphs
- Hash Tables and Hash Maps
- Heaps
- Tries
- And more...

### Algorithms
- Sorting Algorithms (Bubble Sort, Merge Sort, Quick Sort, etc.)
- Searching Algorithms (Linear Search, Binary Search, etc.)
- Graph Algorithms (DFS, BFS, Dijkstra's, etc.)
- Dynamic Programming
- Greedy Algorithms
- String Algorithms
- And more...

## Getting Started

### Prerequisites
- Java 8 or higher
- A Java IDE (IntelliJ IDEA, Eclipse, VS Code) or command line

### Running the Code
1. Clone the repository:
   ```bash
   git clone https://github.com/sabarinathanfwff/DSA.git
   cd DSA
   ```

2. Compile and run Java files:
   ```bash
   javac YourFile.java
   java YourFile
   ```
